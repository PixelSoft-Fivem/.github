### 🚀 About PixelSoft

**PixelSoft** is a FiveM development studio focused on creating modern, highly optimized, and aesthetically pleasing resources for roleplay communities. We reject bloated legacy code in favor of clean architectures, reactive NUI interfaces (Vue 3 / React), and strict resmon budgets (**0.00ms idle**).

Every script is designed to be **framework-agnostic** via our unified bridge library [`px-lib`](https://docs.pxscripts.com/px-lib), giving server owners effortless plug-and-play compatibility across **QBCore**, **ESX Legacy**, and **Qbox**.
